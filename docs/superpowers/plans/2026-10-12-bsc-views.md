# Balanced Scorecard (`bsc`) Views on the New Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-create the old warehouse's 12 `bsc` objects (10 views, 2 tables) on the new ClickHouse server (`172.22.25.214`) with the same names, columns and types, built on the `gold` layer, so the balanced-scorecard report shows Oasis and Oracle Fusion data after only a host change.

**Architecture:**
- **One new gold table.** `fact_gl_fs_monthly` holds monthly GL balances per account. Each branch-month comes from either the Oasis GL or the Fusion GL, switched by `default.map_gl_cutover`.
- **Twelve dbt view models** in a new `marts/bsc/` folder. Each is named `bsc_<object>` with `alias='<object>'`, built as a definer-security view in database `bsc`, with an enforced contract generated from the old server's column types.
- **Reference tables.** Four are copied or loaded into `default` by a PowerShell loader, following the pattern of `load_bi_users.ps1`.
- **Offline checks.** dbt is not installed on HNHANALYTICSSRV. Every model is checked by rendering its SQL with a small Python renderer and running it read-only through the ODBC DSN `HNH_Gold`.
- **Build.** The dbt build, including the unit tests, runs on the receiving server (Ubuntu) in the last task.

**Tech Stack:** dbt-clickhouse (receiving project), ClickHouse 26.5, Python 3.12 + pytest (standard library only), Windows PowerShell 5.1 + Pester 3.4, System.Data.Odbc over the DSNs `HNH_Gold` (new server) and `chDWH` (old server).

**Spec:** `docs/superpowers/specs/2026-10-12-hnh-bsc-views-design.md` (parent: `2026-10-01-hnh-dwh-gold-layer-design.md`).

**Branch:** create `bsc-views` from `main`.

## Global Constraints

- **HNHANALYTICSSRV is the production server** (`CLAUDE.md`).
  - **Ask the user before:**
    - any ClickHouse write, including `scripts/load_bsc_reference.ps1` without `-DryRun`, a `CREATE USER` or a `GRANT`;
    - any dbt build on the receiving server.
  - **Needs no confirmation:** `SELECT`, `DESCRIBE` and `SHOW` through `HNH_Gold` or `chDWH`, pytest, and Pester.
  - Never print or commit a password.
- **dbt conventions:**
  - Work only under `hnh/` folders. Macros are prefixed `hnh_`. No packages, no seeds. YAML uses the `tests:` key.
  - `branch_key` is `UInt8`.
  - Gold tables end with `{{ hnh_settings() }}` when they contain a `left join`. Views set `settings join_use_nulls = 0`, so a missing branch-month gives 0, as in the old views, and columns keep their non-Nullable types.
- **Jinja the renderer understands.** The models in this plan may use only `config()`, `ref()`, `source()`, `var()`, `hnh_settings()` and `hnh_oasis_gl_source()`. There are no `{% %}` statements and no other macros, because `scripts/render_model_sql.py` must be able to render them. Model SQL is ASCII.
- **ClickHouse cautions met before:**
  - An alias that shadows a source column *inside an aggregate* raises error 184: name the intermediate differently.
  - `x.*` after joins can come out with qualified names: list the columns.
  - `union all` branches must have matching types.
  - `ARRAY JOIN` goes directly after `FROM <table>`: do joins in an earlier CTE.
- **Old column types are the contract.** `_bsc__models.yml` is generated from the old server and never edited by hand. Each view casts every column to its old type: `UInt64`, `Date32`, `Decimal(38, 10)`, and so on. Decimal columns are cast from Float64 with `CAST(round(x, 2) AS Decimal(38, 10))`; a plain cast shows binary noise.
- **Branches 1–8 only** in every view and in `fact_gl_fs_monthly`. Group (0) and Head Office (100) are never shown.
- **Windows.** The views evaluate their date windows at query time through `today_ = ifNull(toDateOrNull('{{ var('hnh_bsc_as_of') }}'), today())`. The var is empty in production and set only by unit tests.
- **Shell syntax.** Windows PowerShell 5.1 only: no ternary, no `??`, no `&&`/`||` between commands. Pester 3.4 syntax: `| Should Be`.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

Create `scripts/render_model_sql.py`:

```python
"""Render an hnh dbt model to plain ClickHouse SQL, for read-only checks through an ODBC DSN.

dbt is not installed on HNHANALYTICSSRV. This handles only the Jinja the bsc models use: config(), ref(), source(),
var(), hnh_settings() and hnh_oasis_gl_source(); anything else stops with an error.

  python scripts/render_model_sql.py bsc_vw_financial --inline fact_gl_fs_monthly,stg_bsc__oasis_gl_line \
      --replace stg_ref__gl_cutover=scripts/fixtures/gl_cutover_stub.sql --wrap "DESCRIBE ({model})" --out m.sql

--inline renders a model that is not built yet as a subquery; --replace puts the given SQL in place of a model;
--wrap places the model inside a query (a trailing settings clause moves to the end of the wrapping query).
"""
import argparse
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
MODELS = ROOT / "hnh_dwh" / "models" / "hnh"
PROJECT = ROOT / "hnh_dwh" / "dbt_project.yml"
SOURCE_SCHEMAS = {"reference": "default", "gold_oasis_gl": "gold", "oasis": "oasis", "fusion": "fusion",
                  "press_ganey": "press_ganey", "hnh_log": "gold"}
LAYER_SCHEMAS = {"staging": "stg", "intermediate": "int", "marts": "gold"}


def model_path(name):
    hits = list(MODELS.rglob(f"{name}.sql"))
    if len(hits) != 1:
        raise SystemExit(f"model {name}: {len(hits)} files found")
    return hits[0]


def relation(name):
    path = model_path(name)
    parts = path.relative_to(MODELS).parts
    schema = "bsc" if parts[:2] == ("marts", "bsc") else LAYER_SCHEMAS[parts[0]]
    alias = re.search(r"alias\s*=\s*'([^']+)'", path.read_text(encoding="utf-8"))
    return f"{schema}.{alias.group(1) if alias else name}"


def project_vars():
    found = {}
    for line in PROJECT.read_text(encoding="utf-8").splitlines():
        m = re.match(r"\s+(hnh_\w+):\s*(\"[^\"]*\"|'[^']*'|[^#\s]+)", line)
        if m:
            found[m.group(1)] = m.group(2).strip("\"'")
    return found


def render(name, inline=frozenset(), replace=None, depth=0):
    replace = replace or {}
    sql = model_path(name).read_text(encoding="utf-8")
    if "{%" in sql:
        raise SystemExit(f"{name}: Jinja statements are not supported")
    variables = project_vars()

    def sub(match):
        expr = match.group(1).strip()
        if expr.startswith("config("):
            return ""
        if expr == "hnh_settings()":
            return "" if depth else "settings join_use_nulls = 1"
        m = re.fullmatch(r"ref\('(\w+)'\)", expr)
        if m:
            ref = m.group(1)
            if ref in replace:
                return f"(\n{replace[ref].strip()}\n)"
            if ref in inline:
                return f"(\n{strip_settings(render(ref, inline, replace, depth + 1))[0]}\n)"
            return relation(ref)
        m = re.fullmatch(r"source\('(\w+)',\s*'(\w+)'\)", expr)
        if m:
            return f"{SOURCE_SCHEMAS[m.group(1)]}.{m.group(2)}"
        m = re.fullmatch(r"hnh_oasis_gl_source\('(\w+)'\)", expr)
        if m:
            return f"gold.{m.group(1)}"
        m = re.fullmatch(r"var\('(\w+)'\)", expr)
        if m:
            return variables[m.group(1)]
        raise SystemExit(f"{name}: unsupported Jinja {{{{ {expr} }}}}")

    return re.sub(r"\{\{(.*?)\}\}", sub, sql, flags=re.S).strip()


def strip_settings(sql):
    """Split a trailing `settings ...` line off a rendered model: (sql without it, the settings text or '')."""
    m = re.search(r"\n\s*(settings\s+[^\n]+?)\s*$", sql, flags=re.I)
    if not m:
        return sql, ""
    return sql[: m.start()].rstrip(), m.group(1)


def wrap(sql, template):
    body, settings = strip_settings(sql)
    wrapped = template.replace("{model}", f"\n{body}\n")
    return f"{wrapped}\n{settings}" if settings else wrapped


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("model")
    ap.add_argument("--inline", default="", help="comma-separated models to render as subqueries")
    ap.add_argument("--replace", action="append", default=[], help="model=path.sql: SQL to use in place of a model")
    ap.add_argument("--wrap", default="", help="query containing {model}")
    ap.add_argument("--out", default="", help="write UTF-8 to this file instead of stdout")
    args = ap.parse_args()
    inline = {m for m in args.inline.split(",") if m}
    replace = {}
    for item in args.replace:
        model, path = item.split("=", 1)
        replace[model] = Path(path).read_text(encoding="utf-8")
    sql = render(args.model, inline, replace)
    if args.wrap:
        sql = wrap(sql, args.wrap)
    if args.out:
        Path(args.out).write_text(sql + "\n", encoding="utf-8")
    else:
        sys.stdout.write(sql + "\n")


if __name__ == "__main__":
    main()
```

```powershell
# ClickHouse helpers for the bsc work on HNHANALYTICSSRV, which has no Python ClickHouse driver. Queries go through
# the system ODBC DSNs: HNH_Gold (new server, 172.22.25.214) and chDWH (old server, 172.22.25.165). Invoke-HnhSelect
# runs read-only statements only; writes go through scripts that ask for a credential (load_bsc_reference.ps1).

function Test-HnhReadOnlySql {
    param([Parameter(Mandatory = $true)][string]$Sql)
    $body = ($Sql -replace '(?m)^\s*--.*$', '').Trim().TrimEnd(';').Trim()
    if ($body -match ';') { return $false }
    return [bool]($body -match '(?i)^(SELECT|WITH|DESCRIBE|DESC|SHOW|EXISTS)\b')
}

function Invoke-HnhSelect {
    param(
        [Parameter(Mandatory = $true)][string]$Dsn,
        [Parameter(Mandatory = $true)][string]$Sql,
        [int]$TimeoutSeconds = 900
    )
    if (-not (Test-HnhReadOnlySql -Sql $Sql)) { throw 'Invoke-HnhSelect runs one read-only statement (SELECT, WITH, DESCRIBE, SHOW).' }
    $c = New-Object System.Data.Odbc.OdbcConnection("DSN=$Dsn")
    $c.Open()
    try {
        $cmd = $c.CreateCommand()
        $cmd.CommandText = $Sql
        $cmd.CommandTimeout = $TimeoutSeconds
        $r = $cmd.ExecuteReader()
        $rows = New-Object System.Collections.Generic.List[object]
        while ($r.Read()) {
            $o = [ordered]@{}
            for ($i = 0; $i -lt $r.FieldCount; $i++) {
                if ($r.IsDBNull($i)) { $o[$r.GetName($i)] = $null } else { $o[$r.GetName($i)] = $r.GetValue($i) }
            }
            $rows.Add([pscustomobject]$o)
        }
        $r.Close()
        return ,$rows.ToArray()
    } finally {
        $c.Close()
    }
}

function ConvertTo-HnhTsvField {
    param([AllowNull()][object]$Value)
    if ($null -eq $Value -or $Value -is [System.DBNull]) { return '\N' }
    $s = [System.Convert]::ToString($Value, [System.Globalization.CultureInfo]::InvariantCulture)
    return $s.Replace('\', '\\').Replace("`t", '\t').Replace("`n", '\n').Replace("`r", '\r')
}

function Get-HnhContractColumns {
    param([Parameter(Mandatory = $true)][string]$YamlText, [Parameter(Mandatory = $true)][string]$Model)
    $columns = @()
    $inModel = $false
    $name = $null
    foreach ($line in ($YamlText -split "`r?`n")) {
        if ($line -match '^  - name: (\S+)\s*$') { $inModel = ($Matches[1] -eq $Model); continue }
        if (-not $inModel) { continue }
        if ($line -match '^      - name: (\S+)\s*$') { $name = $Matches[1]; continue }
        if ($name -and $line -match '^        data_type: "(.*)"\s*$') {
            $columns += [pscustomobject]@{ Name = $name; Type = $Matches[1] }
            $name = $null
        }
    }
    return ,$columns
}

function Compare-HnhColumns {
    param([object[]]$Expected, [object[]]$Actual)
    $problems = @()
    $max = [Math]::Max($Expected.Count, $Actual.Count)
    for ($i = 0; $i -lt $max; $i++) {
        $e = $null; $a = $null
        if ($i -lt $Expected.Count) { $e = $Expected[$i] }
        if ($i -lt $Actual.Count) { $a = $Actual[$i] }
        if ($null -eq $e) { $problems += "column $($i + 1): unexpected $($a.Name) $($a.Type)"; continue }
        if ($null -eq $a) { $problems += "column $($i + 1): missing $($e.Name) $($e.Type)"; continue }
        if ($e.Name -cne $a.Name -or $e.Type -cne $a.Type) {
            $problems += "column $($i + 1): expected $($e.Name) $($e.Type), got $($a.Name) $($a.Type)"
        }
    }
    return ,$problems
}

function Compare-HnhBscRows {
    param([object[]]$Old, [object[]]$New, [string[]]$Keys, [string[]]$Columns, [double]$Tolerance = 0.005)
    $index = @{}
    foreach ($n in $New) { $index[(($Keys | ForEach-Object { [string]$n.$_ }) -join '|')] = $n }
    $seen = @{}
    $out = @()
    foreach ($o in $Old) {
        $k = ($Keys | ForEach-Object { [string]$o.$_ }) -join '|'
        $seen[$k] = $true
        $n = $index[$k]
        if ($null -eq $n) { $out += [pscustomobject]@{ Key = $k; Column = '*'; Old = $null; New = $null; Status = 'missing in new' }; continue }
        foreach ($c in $Columns) {
            $ov = 0.0; $nv = 0.0
            if ($null -ne $o.$c) { $ov = [double]$o.$c }
            if ($null -ne $n.$c) { $nv = [double]$n.$c }
            $scale = [Math]::Max([Math]::Abs($ov), 1.0)
            if ([Math]::Abs($nv - $ov) / $scale -gt $Tolerance) {
                $out += [pscustomobject]@{ Key = $k; Column = $c; Old = $ov; New = $nv; Status = 'differs' }
            }
        }
    }
    foreach ($k in $index.Keys) {
        if (-not $seen.ContainsKey($k)) { $out += [pscustomobject]@{ Key = $k; Column = '*'; Old = $null; New = $null; Status = 'missing in old' } }
    }
    return ,$out
}

function New-HnhTableDdl {
    param([Parameter(Mandatory = $true)][string]$Table, [Parameter(Mandatory = $true)][object[]]$Columns)
    $cols = ($Columns | ForEach-Object { "``$($_.name)`` $($_.type)" }) -join ', '
    return "CREATE TABLE IF NOT EXISTS $Table ($cols) ENGINE = MergeTree ORDER BY tuple()"
}

function Test-HnhGlCutover {
    param([object[]]$Rows)
    $problems = @()
    foreach ($r in $Rows) {
        if ($r.BRANCH_ID -notmatch '^[1-8]$') { $problems += "BRANCH_ID '$($r.BRANCH_ID)' is not 1-8" }
        if ($r.FIRST_FUSION_GL_MONTH -notmatch '^20\d\d(0[1-9]|1[0-2])$') {
            $problems += "branch $($r.BRANCH_ID): FIRST_FUSION_GL_MONTH '$($r.FIRST_FUSION_GL_MONTH)' is not YYYYMM"
        }
    }
    $dupes = @($Rows | Group-Object BRANCH_ID | Where-Object Count -gt 1 | ForEach-Object Name)
    if ($dupes.Count) { $problems += "duplicate BRANCH_ID: $($dupes -join ', ')" }
    return ,$problems
}
```

```sql

-- Monthly GL balances per branch and account for the bsc finance views (bsc spec section 5). Each branch-month takes
-- one source: the Oasis GL before the branch's first Fusion GL month (default.map_gl_cutover; no row = Oasis), the
-- Fusion GL from it, because after go-live the Oasis feed keeps posting revenue that Fusion also has. Branches 1-8.
-- Amounts are debit positive. Oasis: posted lines; opening = this fiscal year's brought-forward rows + earlier months
-- of the year, so income-statement accounts restart each year. Fusion: including unposted (Oasis-feed batches stay
-- unposted), go-live opening-balance journals kept apart in opening_journal_amount.
with cutover as (
    select branch_id, first_fusion_gl_month_start
    from {{ ref('stg_ref__gl_cutover') }}
),

oasis_month as (
    select
        l.branch_key                               as branch_key,
        l.oasis_gl_account_key                     as oasis_gl_account_key,
        assumeNotNull(l.month_start)               as month_start,
        sumIf(l.amount, l.is_brought_forward = 1)  as bf_amount,
        sumIf(l.amount, l.is_brought_forward = 0)  as mv_amount
    from {{ ref('stg_bsc__oasis_gl_line') }} as l
    where l.is_posted = 1
      and l.branch_key between 1 and 8
      and l.month_start >= toDate('{{ var('hnh_history_start_date') }}')
    group by branch_key, oasis_gl_account_key, month_start
),

oasis_last as (
    select branch_key, max(month_start) as last_month
    from oasis_month
    group by branch_key
),

-- every month from an account's first row in a year to December (or the branch's last month), so a balance carries
-- through months without postings
oasis_account_year as (
    select
        m.branch_key              as branch_key,
        m.oasis_gl_account_key    as oasis_gl_account_key,
        toYear(m.month_start)     as fiscal_year,
        min(m.month_start)        as first_month,
        any(t.last_month)         as last_month
    from oasis_month as m
    inner join oasis_last as t on t.branch_key = m.branch_key
    group by branch_key, oasis_gl_account_key, fiscal_year
),

oasis_grid as (
    select branch_key, oasis_gl_account_key, addMonths(first_month, toInt32(n)) as month_start
    from oasis_account_year
    array join range(toUInt32(dateDiff('month', first_month, least(makeDate(fiscal_year, 12, 1), last_month)) + 1)) as n
),

oasis_rolled as (
    select
        g.branch_key                      as branch_key,
        g.oasis_gl_account_key            as oasis_gl_account_key,
        g.month_start                     as month_start,
        ifNull(m.bf_amount, 0)            as oj_amount,
        ifNull(m.mv_amount, 0)            as mv,
        sum(ifNull(m.bf_amount, 0) + ifNull(m.mv_amount, 0)) over (
            partition by g.branch_key, g.oasis_gl_account_key, toYear(g.month_start)
            order by g.month_start rows between unbounded preceding and 1 preceding) as open_amount
    from oasis_grid as g
    left join oasis_month as m
      on m.branch_key = g.branch_key and m.oasis_gl_account_key = g.oasis_gl_account_key and m.month_start = g.month_start
),

oasis as (
    select
        r.branch_key                                               as branch_key,
        r.month_start                                              as month_start,
        'oasis'                                                    as source_system,
        ifNull(a.account_code, toString(r.oasis_gl_account_key))  as account_code,
        ifNull(a.fs_type, '')                                      as fs_type,
        ifNull(a.fs_element, '')                                   as fs_element,
        ifNull(a.fs_category, '')                                  as fs_category,
        ifNull(a.fs_caption, '')                                   as fs_caption,
        ifNull(a.fs_line, '')                                      as fs_line,
        sum(r.open_amount)                                         as opening_amount,
        sum(r.oj_amount)                                           as opening_journal,
        sum(r.mv)                                                  as movement_amount
    from oasis_rolled as r
    left join {{ ref('stg_bsc__oasis_gl_account') }} as a on a.oasis_gl_account_key = r.oasis_gl_account_key
    group by branch_key, month_start, account_code, fs_type, fs_element, fs_category, fs_caption, fs_line
),

fusion as (
    select
        f.branch_key                                                as branch_key,
        p.month_start                                               as month_start,
        'fusion'                                                    as source_system,
        toString(f.gl_account_key)                                  as account_code,
        lower(d.fs_type)                                            as fs_type,
        lower(d.fs_element)                                         as fs_element,
        lower(d.fs_category)                                        as fs_category,
        lower(d.fs_caption)                                         as fs_caption,
        lower(d.fs_line)                                            as fs_line,
        -- an adjustment period folds into its quarter's last month: its movement counts, its opening does not
        sumIf(f.opening_balance, p.is_adjustment = 0)               as opening_amount,
        sum(f.period_movement - f.period_movement_excl_opening)     as opening_journal,
        sum(f.period_movement_excl_opening)                         as movement_amount
    from {{ ref('fact_gl_balance_monthly') }} as f
    inner join {{ ref('hnh_dim_gl_period') }} as p on p.period_key = f.period_key
    inner join {{ ref('hnh_dim_gl_account') }} as a on a.gl_account_key = f.gl_account_key
    inner join {{ ref('dim_fs_line') }} as d on d.fs_line_key = a.fs_line_key
    where f.balance_view = 'including_unposted'
      and f.branch_key between 1 and 8
    group by branch_key, month_start, account_code, fs_type, fs_element, fs_category, fs_caption, fs_line
),

selected as (
    select o.branch_key as branch_key, o.month_start as month_start, o.source_system as source_system,
           o.account_code as account_code, o.fs_type as fs_type, o.fs_element as fs_element,
           o.fs_category as fs_category, o.fs_caption as fs_caption, o.fs_line as fs_line,
           o.opening_amount as opening_amount, o.opening_journal as opening_journal, o.movement_amount as movement_amount
    from oasis as o
    left join cutover as c on c.branch_id = o.branch_key
    where c.first_fusion_gl_month_start is null or o.month_start < c.first_fusion_gl_month_start
    union all
    select fu.branch_key, fu.month_start, fu.source_system, fu.account_code, fu.fs_type, fu.fs_element,
           fu.fs_category, fu.fs_caption, fu.fs_line, fu.opening_amount, fu.opening_journal, fu.movement_amount
    from fusion as fu
    inner join cutover as c on c.branch_id = fu.branch_key
    where fu.month_start >= c.first_fusion_gl_month_start
)

select
    toUInt8(branch_key)                                    as branch_key,
    month_start,
    toLowCardinality(source_system)                        as source_system,
    account_code,
    toLowCardinality(fs_type)                              as fs_type,
    toLowCardinality(fs_element)                           as fs_element,
    toLowCardinality(fs_category)                          as fs_category,
    toLowCardinality(fs_caption)                           as fs_caption,
    toLowCardinality(fs_line)                              as fs_line,
    opening_amount                                         as opening_balance,
    opening_journal                                        as opening_journal_amount,
    movement_amount                                        as movement,
    opening_amount + opening_journal + movement_amount     as closing_balance,
    now()                                                  as _loaded_at
from selected
where abs(opening_amount) >= 0.005 or abs(opening_journal) >= 0.005 or abs(movement_amount) >= 0.005
{{ hnh_settings() }}
```

```sql
{{ config(alias='vw_financial') }}

-- Old bsc.vw_financial (bsc spec 6.3). Actuals from fact_gl_fs_monthly (Oasis or Fusion per branch-month) with FS
-- value lists that hold in both vocabularies: Oasis keeps depreciation under direct cost and books medicines as
-- cost of goods sold; Fusion has a depreciation category and cost of medicines. EBITDA = net revenue - operating
-- expenses, as before. Budget: fact_income_statement_monthly, most likely; NULL when the branch-month has none.
-- Months from January two years back; budget-only months are kept.
with
    ifNull(toDateOrNull('{{ var('hnh_bsc_as_of') }}'), today()) as today_,
    makeDate(toYear(today_ - 1) - 2, 1, 1) as from_month_,
actual as (
    select
        branch_key,
        month_start,
        -sumIf(movement, fs_element = 'revenue')                                                     as net_rev,
        -sumIf(movement, fs_element = 'revenue' and fs_caption != 'revenue - settlement discount')   as sub_rev,
        sumIf(movement, fs_element = 'expenses'
                        and fs_category not in ('finance cost', 'zakat', 'depreciation and amortization')
                        and fs_caption not in ('depreciation', 'depreciation on rou', 'amortization of intangible assets',
                                               'depreciation expense', 'amortization expense'))      as opex,
        sumIf(movement, fs_category = 'general and administrative expenses')                         as ga,
        sumIf(movement, fs_caption in ('medical consumables', 'cost of medicines', 'cost of goods sold')) as consumables,
        -sumIf(movement, fs_type = 'is')                                                             as income,
        sumIf(closing_balance, fs_caption = 'trade receivables, net')                                as ar_close,
        sumIf(opening_balance + opening_journal_amount, fs_caption = 'trade receivables, net')       as ar_open,
        sumIf(closing_balance, fs_element = 'assets')                                                as assets_close,
        sumIf(opening_balance + opening_journal_amount, fs_element = 'assets')                       as assets_open
    from {{ ref('fact_gl_fs_monthly') }}
    where month_start >= from_month_
    group by branch_key, month_start
),
budget as (
    select
        branch_key,
        month_start,
        sumIf(budget_most_likely, budget_line_code = 'REV_NET')                                      as net_rev_b,
        sumIf(budget_most_likely, budget_line_code = 'REV_SUB')                                      as sub_rev_b,
        sumIf(budget_most_likely, budget_line_code in ('TOTAL_DC', 'TOTAL_GA'))                      as opex_b,
        sumIf(budget_most_likely, budget_line_code = 'EBITDA')                                       as ebitda_b,
        sumIf(budget_most_likely, budget_line_code = 'TOTAL_GA')
            - sumIf(budget_most_likely, budget_line_code = 'GA_MARKETING')                           as ga_b,
        sumIf(budget_most_likely, budget_line_code in ('DC_MEDICINES', 'DC_CONSUMABLES'))            as consumables_b
    from {{ ref('fact_income_statement_monthly') }}
    where branch_key between 1 and 8 and month_start >= from_month_
    group by branch_key, month_start
    having countIf(budget_most_likely != 0) > 0
),
keys as (
    select branch_key, month_start from actual
    union distinct
    select branch_key, month_start from budget
)
select
    toUInt64(k.branch_key)                                                 as branch_id,
    toNullable(toDate32(k.month_start))                                    as month_date,
    CAST(round(ifNull(a.net_rev, 0), 2) AS Decimal(38, 10))                as net_revenue_actual,
    CAST(round(ifNull(a.sub_rev, 0), 2) AS Decimal(38, 10))                as sub_revenue_actual,
    CAST(round(ifNull(a.opex, 0), 2) AS Decimal(38, 10))                   as operating_expenses,
    CAST(round(ifNull(a.net_rev, 0) - ifNull(a.opex, 0), 2) AS Decimal(38, 10)) as ebitda_actual,
    CAST(round(ifNull(a.ar_close, 0), 2) AS Decimal(38, 10))               as account_receivable_actual,
    CAST(round(ifNull(a.ar_open, 0), 2) AS Decimal(38, 10))                as account_receivable_actual_opening_balance,
    CAST(round(ifNull(a.ga, 0), 2) AS Decimal(38, 10))                     as ga_expenses_actual,
    CAST(round(ifNull(a.consumables, 0), 2) AS Decimal(38, 10))            as consumables_actual,
    CAST(round(ifNull(a.assets_close, 0), 2) AS Decimal(38, 10))           as assets,
    CAST(round(ifNull(a.assets_open, 0), 2) AS Decimal(38, 10))            as assets_opening_balance,
    CAST(round(ifNull(a.income, 0), 2) AS Decimal(38, 10))                 as income,
    CAST(round(b.net_rev_b, 2) AS Nullable(Decimal(38, 2)))                as net_revenue_budget,
    CAST(round(b.sub_rev_b, 2) AS Nullable(Decimal(38, 2)))                as sub_revenue_budget,
    CAST(round(b.opex_b, 2) AS Nullable(Decimal(38, 2)))                   as operating_expenses_budget,
    CAST(round(b.ebitda_b, 2) AS Nullable(Decimal(38, 2)))                 as ebitda_budget,
    CAST(round(b.ga_b, 2) AS Nullable(Decimal(38, 2)))                     as ga_expenses_budget,
    CAST(round(b.consumables_b, 2) AS Nullable(Decimal(38, 2)))            as consumables_budget
from keys as k
left join actual as a on a.branch_key = k.branch_key and a.month_start = k.month_start
left join budget as b on b.branch_key = k.branch_key and b.month_start = k.month_start
settings join_use_nulls = 1
```

```sql
-- Old bsc.vw_customer on gold (bsc spec 7.2): revenue, visits, admissions, capacity and targets per branch and
-- month, from January of last year to yesterday, with the SSAS measure definitions. Revenue splits by payer use the
-- episode payer (co-pay stays with the insurer, as before); high-value volume uses the booked doctor; capacity is
-- the old clinic-hours rule (legacy_capacity_slots, O-B3). Targets: most-likely scenario.
with
    ifNull(toDateOrNull('{{ var('hnh_bsc_as_of') }}'), today()) as today_,
    today_ - 1 as yesterday_,
    toInt32(toYYYYMMDD(subtractYears(toStartOfYear(yesterday_), 1))) as from_key_,
    toInt32(toYYYYMMDD(yesterday_)) as to_key_,
months as (
    select date_key, toDate32(start_of_month) as period
    from {{ ref('dim_date') }}
    where date_key between from_key_ and to_key_
),
referral as (
    select episode_key, is_referral_policy
    from {{ ref('fact_episode') }}
),
rev as (
    select
        c.branch_key                                                                  as branch_key,
        m.period                                                                      as period,
        sum(c.revenue_amount)                                                         as revenue,
        sumIf(c.revenue_amount, c.care_type_key = 1)                                  as op_revenue,
        sumIf(c.revenue_amount, c.care_type_key = 3 and c.is_ltc = 0)                 as non_ltc_ip_revenue,
        sumIf(c.revenue_amount, c.care_type_key = 1
              and pc.category_code in ('MD', 'MED', 'CSM', 'RTL', 'MLK', 'PH', 'LAB', 'RAD')) as ancillary_services_revenue,
        sumIf(c.revenue_amount, p.is_moh = 0)                                         as non_moh_revenue,
        sumIf(c.revenue_amount, p.category = 'Insurance')                             as insurance_revenue,
        sumIf(c.revenue_amount, ep.is_referral_policy = 1)                            as referrals_revenue,
        sumIf(c.revenue_amount, p.billing_type = 'Credit')                            as credit_revenue,
        sumIf(c.revenue_amount, s.is_high_value_specialty = 1)                        as high_value_service_revenue
    from {{ ref('fact_charge_line') }} as c
    inner join months as m on m.date_key = c.delivery_date_key
    left join {{ ref('dim_payer') }} as p on p.payer_key = c.episode_payer_key
    left join {{ ref('dim_staff') }} as s on s.staff_key = c.staff_key
    left join {{ ref('dim_product_category') }} as pc on pc.product_category_key = c.product_category_key
    left join referral as ep on ep.episode_key = c.episode_key
    where c.delivery_date_key between from_key_ and to_key_ and c.branch_key between 1 and 8

),
cen as (
    select
        e.branch_key                                                                  as branch_key,
        m.period                                                                      as period,
        countIf(e.encounter_type = 'OP' and e.is_arrived = 1 and e.is_cancelled = 0)
          + countIf(e.encounter_type = 'ER' and e.is_cancelled = 0)                   as census,
        countIf(((e.encounter_type = 'OP' and e.is_arrived = 1) or e.encounter_type = 'ER')
                and e.is_cancelled = 0 and p.category = 'Insurance')                  as insurance_census,
        countIf(e.encounter_type = 'OP' and e.is_arrived = 1 and e.is_cancelled = 0)  as op_census,
        uniqExactIf(e.patient_key, e.is_arrived = 1 and e.is_cancelled = 0)           as distinct_patients,
        uniqExactIf(e.patient_key, e.is_arrived = 1 and e.is_cancelled = 0 and e.is_returning = 1) as returning_patients,
        countIf(e.encounter_type = 'OP' and e.is_arrived = 1 and e.visit_type = 'New patient') as new_op_census,
        countIf(e.encounter_type = 'ER' and e.is_cancelled = 0)                       as er_census,
        countIf(((e.encounter_type = 'OP' and e.is_arrived = 1) or e.encounter_type = 'ER')
                and e.is_cancelled = 0 and ep.is_referral_policy = 1)                 as referrals_census,
        countIf(((e.encounter_type = 'OP' and e.is_arrived = 1) or e.encounter_type = 'ER')
                and e.is_cancelled = 0 and s.is_high_value_specialty = 1)             as high_value_service_census,
        sumIf(e.wait_minutes, e.encounter_type = 'OP' and e.is_arrived = 1 and e.is_cancelled = 0) as op_wait
    from {{ ref('fact_encounter') }} as e
    inner join months as m on m.date_key = e.encounter_date_key
    left join {{ ref('dim_payer') }} as p on p.payer_key = e.payer_key
    left join {{ ref('dim_staff') }} as s on s.staff_key = e.booked_staff_key
    left join referral as ep on ep.episode_key = e.episode_key
    where e.encounter_date_key between from_key_ and to_key_ and e.encounter_type in ('OP', 'ER')
      and e.branch_key between 1 and 8
    group by branch_key, period
),
epi as (

adm as (

    from {{ ref('fact_admission') }} as a

    left join {{ ref('dim_payer') }} as p on p.payer_key = a.payer_key

    group by branch_key, period

disc as (

        m.period                                            as period,
        count()                                             as discharges,
        countIf(b.is_critical = 1)                          as icu_discharges,
        avgIf(a.los_days, a.is_ltc = 0)                     as alos_non_ltc_days
    from {{ ref('fact_admission') }} as a

    left join {{ ref('dim_bed') }} as b on b.bed_key = a.last_bed_key
    where a.physical_discharge_date_key between from_key_ and to_key_ and a.is_countable = 1 and a.branch_key between 1 and 8
    group by branch_key, period
),
cap as (

    from {{ ref('agg_clinic_capacity_daily') }} as k
    inner join months as m on m.date_key = k.date_key
    where k.date_key between from_key_ and to_key_ and k.branch_key between 1 and 8

),
bud as (

        t.branch_key                                                                        as branch_key,
        m.period                                                                            as period,
        sum(t.target_revenue)                                                               as revenue_target,
        round(sum(t.target_census), 0)                                                      as volume_target,
        round(sumIf(t.target_revenue, t.creditor != 'Government'), 0)                       as non_moh_revenue_target,
        round(sumIf(t.target_revenue, t.creditor = 'Insurance'), 0)                         as insurance_revenue_target,
        round(sumIf(t.target_census, t.creditor = 'Insurance'), 0)                          as insurance_census_target,
        round(sumIf(t.target_revenue, t.care_type_key = 1), 0)                              as op_revenue_target,
        round(sumIf(t.target_revenue, t.care_type_key = 3 and t.stay_type != 'LTC'), 0)     as non_ltc_ip_revenue_target,
        round(sumIf(t.target_revenue, t.care_type_key = 1), 0) * 0.6                        as ancillary_revenue_target,

    from {{ ref('fact_target_daily') }} as t

    where t.date_key between from_key_ and to_key_ and t.scenario = 'most_likely' and t.branch_key between 1 and 8
    group by branch_key, period
),
keys as (
    select b.branch_key as branch_key, m.period as period
    from {{ ref('hnh_dim_branch') }} as b
    cross join (select distinct period from months) as m
    where b.branch_key between 1 and 8
)
select

    k.period                                                                  as period,
    CAST(round(r.revenue, 2) AS Decimal(38, 10))                              as revenue,
    CAST(round(r.op_revenue, 2) AS Decimal(38, 10))                           as op_revenue,
    CAST(round(r.non_ltc_ip_revenue, 2) AS Decimal(38, 10))                   as non_ltc_ip_revenue,
```

```sql
-- Old bsc.vw_hospital_beds_utilization (bsc spec 7.3): stays in house during the month (countable admissions),
-- discharge ALOS (SSAS ALOS (days)) and bed nights of inpatient, non-excluded wards (SSAS Bed Occupancy %) per branch
-- and month from January of last year. available_beds is the month's average available beds. Months with stays only.
with
    ifNull(toDateOrNull('{{ var('hnh_bsc_as_of') }}'), today()) as today_,
    today_ - 1 as yesterday_,
    subtractYears(toStartOfYear(yesterday_), 1) as from_date_,
months as (
    select distinct start_of_month as period, end_of_month
    from {{ ref('dim_date') }}
    where date_day between from_date_ and yesterday_
),
stays as (
    select a.branch_key as branch_key, m.period as period,
           count() as stays_in_house, countIf(a.is_ltc_to_date = 1) as ltc_stays
    from {{ ref('fact_admission') }} as a
    cross join months as m
    where a.is_countable = 1 and a.branch_key between 1 and 8
      and toDate(a.admitted_at) <= m.end_of_month
      and toDate(coalesce(a.physical_discharge_at, now())) >= m.period
    group by branch_key, period
),
occupancy as (
    select branch_key, toStartOfMonth(YYYYMMDDToDate(toUInt32(date_key))) as period,
           sum(is_available) as bed_days_available, sum(is_occupied) as bed_days_occupied, uniqExact(date_key) as days
    from {{ ref('fact_bed_occupancy_daily') }}
```

```sql
-- headcount (employees, not contingent) from hnh_hr_snapshot_start, paid people (gross pay > 0, no parallel run)

staff as (

           any(staff_key) as paid_staff_key

    group by branch_key, period, paid_person_key
    having sum(gross_pay) > 0
),
people as (
    select h.branch_key as branch_key, toStartOfMonth(h.month_end) as period, toString(h.employee_key) as person_id,

    from {{ ref('fact_headcount_monthly') }} as h
    where h.is_contingent = 0 and h.headcount > 0 and toStartOfMonth(h.month_end) >= fusion_start_

    from paid
    where period < fusion_start_

           uniqExactIf(p.person_id, s.category = 'DOCTORS')                   as hc_doctors,

    toUInt64(h.hc_doctors + pt.pt_doctors)                   as doctors_headcount,
    toUInt64(pt.pt_doctors)                                  as pt_doctors_headcount,
    toFloat64(h.fte_total + 0.5 * pt.pt_doctors)             as FTE
from spine as sp
left join heads as h on h.branch_key = sp.branch_key and h.period = sp.period
```

```powershell
    powershell -ExecutionPolicy Bypass -File scripts\compare_bsc.ps1 [-Months 2026-08-01] [-Year 2025]
#>
param([string[]]$Months = @('2026-08-01'), [int]$Year = 2025, [double]$Tolerance = 0.005, [int]$MaxRows = 200)
$ErrorActionPreference = 'Stop'
Import-Module (Join-Path $PSScriptRoot 'HnhCh.psm1') -Force
$glKeys = @('BranchId', 'Period', 'AccountType', 'FS_ELEMENT', 'FS_CATEGORY', 'FS_CAPTION', 'FS_LINE')
$views = @(
    @{ View = 'vw_customer'; Keys = @('branch_id', 'period'); Date = 'period' },
    @{ View = 'vw_financial'; Keys = @('branch_id', 'month_date'); Date = 'month_date' },
    @{ View = 'vw_gl_transactions'; Keys = $glKeys; Date = 'Period' },
    @{ View = 'vw_gl_openning_balance'; Keys = $glKeys; Date = 'Period' },
    @{ View = 'vw_hospital_beds_utilization'; Keys = @('hospital_id', 'period'); Date = 'period' },
    @{ View = 'vw_rcm'; Keys = @('hospital_id', 'period'); Date = 'period' },
    @{ View = 'vw_work_force'; Keys = @('branch_id', 'period'); Date = 'period' },
    @{ View = 'vw_income_statement_budget'; Keys = @('branch_id', 'line_item_code', 'month_date'); Date = 'month_date' },
    @{ View = 'vw_hospital'; Keys = @('Id', 'Hospital', 'City'); Date = $null },
    @{ View = 'vw_date_dim'; Keys = @('Date'); Date = 'Date' },
    @{ View = 'targets'; Keys = @('hospital_id', 'period_id', 'kpi_no', 'strategy_segment'); Date = $null },
    @{ View = 'patient_satisfaction'; Keys = @('hospital_id', 'period_id'); Date = $null }
)
$monthList = ($Months | ForEach-Object { "'$_'" }) -join ', '
$lines = New-Object System.Collections.Generic.List[string]
$lines.Add('# bsc views: old server against new (generated)')
$lines.Add('')
$lines.Add("Generated $(Get-Date -Format 'yyyy-MM-dd HH:mm') by scripts/compare_bsc.ps1. Months: $($Months -join ', ') and the year $Year. Tolerance: $($Tolerance * 100)% relative (absolute below 1). Attribution: docs/reconciliation_bsc.md.")
foreach ($v in $views) {
    $types = Invoke-HnhSelect -Dsn chDWH -Sql "SELECT name, type FROM system.columns WHERE database = 'bsc' AND table = '$($v.View)' ORDER BY position"
    $numeric = @($types | Where-Object { $v.Keys -notcontains $_.name -and $_.type -match 'Int|Float|Decimal' } | ForEach-Object { $_.name })
    $keySql = @(for ($i = 0; $i -lt $v.Keys.Count; $i++) { "toString(``$($v.Keys[$i])``) AS key_$i" })
    $valSql = @(for ($i = 0; $i -lt $numeric.Count; $i++) { "toFloat64(sum(``$($numeric[$i])``)) AS val_$i" })
    $keyNames = @(for ($i = 0; $i -lt $v.Keys.Count; $i++) { "key_$i" })
    $valNames = @(for ($i = 0; $i -lt $numeric.Count; $i++) { "val_$i" })
    $where = ''
    if ($v.Date) {
        $d = "toDate(``$($v.Date)``)"
        $where = "WHERE toStartOfMonth($d) IN ($monthList) OR toYear($d) = $Year"
    }
    $sql = "SELECT $(($keySql + $valSql) -join ', ') FROM bsc.``$($v.View)`` $where GROUP BY $($keyNames -join ', ')"
    $old = @(Invoke-HnhSelect -Dsn chDWH -Sql $sql)
    $new = @(Invoke-HnhSelect -Dsn HNH_Gold -Sql $sql)
    $diffs = @(Compare-HnhBscRows -Old $old -New $new -Keys $keyNames -Columns $valNames -Tolerance $Tolerance)
    $lines.Add('')
    $lines.Add("## $($v.View)")
    $lines.Add('')
    $lines.Add("Keys ($($v.Keys -join ', ')): old $($old.Count), new $($new.Count). Differences: $($diffs.Count).")
    if ($diffs.Count -eq 0) { continue }
    $lines.Add('')
    $lines.Add('| Key | Column | Old | New | Status |')
    $lines.Add('|---|---|---|---|---|')
    foreach ($d in ($diffs | Select-Object -First $MaxRows)) {
        $col = $d.Column
        if ($col -like 'val_*') { $col = $numeric[[int]($col.Substring(4))] }
        $lines.Add("| $($d.Key) | $col | $($d.Old) | $($d.New) | $($d.Status) |")
    }
    if ($diffs.Count -gt $MaxRows) { $lines.Add("| ... | $($diffs.Count - $MaxRows) more | | | |") }
}
$out = Join-Path $PSScriptRoot '..\docs\reconciliation_bsc_differences.md'
[IO.File]::WriteAllText($out, ($lines -join "`n") + "`n", (New-Object System.Text.UTF8Encoding $false))
Write-Host "wrote $out"
```

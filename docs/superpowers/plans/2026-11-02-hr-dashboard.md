# HR Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An HR report on Power BI Report Server in BSC branding (Home, Executive story, KPI scorecard, six detail pages, Data quality, Guide), fed by HR config tables in ClickHouse, HR data-quality marts and an `HR Dashboard` perspective of `HNH_Analytics`.

**Architecture:** Three layers, built in order, each gated by the user before anything touches the server:
- **A. Config and dbt:** `default.map_hr_*` change-log tables (KPI list, targets, data quality catalogue), their staging models, the `marts/hr/` models, and `ssas_*` views.
- **B. SSAS:** four new tables, an `HR Dashboard\…` measure folder (KPI framework, new KPIs, story sentences, data quality counts) and a perspective.
- **C. Report:** `powerbi_tmdl/hnh_hr_report/`, a Python PBIR generator that reuses the BSC generator's modules after they are parameterised.

**Tech Stack:** dbt (ClickHouse, run in the receiving project on 172.22.25.214); SSAS Tabular TMDL generated by `ssas/tools`; Python 3.12, pytest, Pester (Windows PowerShell 5.1); PBIR → legacy `.pbix` for Report Server.

**Spec:** `docs/superpowers/specs/2026-11-02-hr-dashboard-design.md`

## Review Focus

1. **Missing target treated as 0.** In DAX, `A <= BLANK()` compares against 0, so a KPI without a target would show At risk or On track. A blank target must give `No target yet`. (Task 7, test `status_no_target_2025`.)
2. **Users without pay access** (all `EXE_*`). The pay KPIs, story blocks and tiles must say `Requires pay access`, never `No data`, an error, or a guard message. (Tasks 7 and 8; security stage at GATE G2 and the `EXE_ABH` check at GATE G4.)
3. **Guard messages on new slices.** `HR KPI Actual` shown by `HR KPI` rows, and data quality counts on a page with a Month slicer, must not return "… can't be analysed by …". Use `annotation hnh_guard_allow` where the slice is intended. (Tasks 7 and 8, tests `actual_by_kpi_row_no_guard` and `dq_count_ignores_month`.)
4. **All hospitals versus one hospital.**
   - The network target is the average of the hospital targets, as in the BSC.
   - A one-hospital user (`EXE_ABH`) sees their own hospital's target and status, and no Head Office (100) data quality records.

   (Task 3 test `fallback_branch0_fills_all_hospitals`; GATES G2 and G4.)
5. **No prior year before 2027.** Headcount starts 2026-01, so year-on-year phrases must read "no prior-year data", not "+100%" or "0%". (Task 8, test `story_size_no_prior_year`.)

*Per-KPI lookups:*

  2. `Requires pay access` when `needs_pay` = 1 and `[HR Can See Pay]` = 0.
